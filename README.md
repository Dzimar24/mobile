# Android Development Learning & Workshop Repository

Koleksi implementasi praktikum dan eksplorasi modul pemrograman Android yang berisi Kotlin & Java. Repositori ini berfungsi sebagai catatan kode terstruktur dan referensi cepat untuk peninjauan implementasi tanpa harus membuka Android Studio yang berat secara lokal.

---

## 📌 Daftar Proyek & Materi

| Folder         | Bahasa        | Topik / Fitur Utama       | Deskripsi Singkat                                                                              |
| :------------- | :------------ | :------------------------ | :--------------------------------------------------------------------------------------------- |
| **Mobile 9.1** | Kotlin / Java | Layout Dasar              | Pengenalan tata letak antarmuka dasar.                                                         |
| **Mobile 9.2** | Kotlin / Java | View & ViewGroups         | Penataan komponen UI turunan.                                                                  |
| **Mobile 10**  | Kotlin / Java | Layouting Form & Navigasi | Desain input form dan perpindahan activity dasar.                                              |
| **Mobile 11**  | Kotlin / Java | Event Handling            | Penanganan aksi input pengguna dan listener.                                                   |
| **Mobile 12**  | Kotlin / Java | UI Components             | Eksplorasi komponen antarmuka standar.                                                         |
| **Mobile 14**  | Kotlin / Java | Advance Layouting         | Optimasi antarmuka dan penataan hierarki view.                                                 |
| **Mobile 15**  | Kotlin / Java | RecyclerView & CardView   | Menampilkan daftar data mahasiswa dinamis menggunakan custom adapter dan CardView.             |
| **Mobile 18**  | Kotlin / Java | Fragment Navigation       | Pergantian tampilan dinamis di dalam satu Activity menggunakan FirstFragment & SecondFragment. |
| **Mobile 22**  | Kotlin / Java | Implicit Intent           | Menjalankan pencarian URL dan membuka peramban web eksternal melalui Intent implisit.          |
